# OFFICE LEASING Brand Positioning

## 1. 핵심 포지셔닝

`officeleasing.co.kr`은 `hintoffice.com`의 단순 확장판이 아니라, 서울 전역의 프라임 오피스 임대 정보를 전문적으로 제공하는 별도 브랜드 플랫폼이다.

핵심 키워드는 **사무실 임대**이며, 지역 범위와 상품 범위 모두를 확대한다.

## 2. hintoffice.com과의 핵심 차별점

### 지역 범위

- `hintoffice.com`: 강남권 중심의 중소형 사무실 임대
- `officeleasing.co.kr`: GBD, YBD, CBD를 포함해 성수, 송파, 서초, 용산 등 서울 전역의 주요 오피스 권역

OFFICE LEASING는 강남 사무실 임대에 머물지 않고 서울 전체의 업무권역을 다루는 것을 기본 전제로 한다.

### 상품 범위

- `hintoffice.com`: 중소형 사무실 비중이 높음
- `officeleasing.co.kr`: 프라임 오피스, 대형 빌딩, 기업형 오피스, 주요 업무지구의 전문 빌딩 정보에 집중

빌딩 자체의 브랜드, 규모, 입지, 공용부, 운영 품질, 주차, 접근성, 현재 공실과 임대조건을 전문적으로 제공한다.

### 사용자 경험

OFFICE LEASING는 다음을 핵심 품질 기준으로 둔다.

1. 빠른 로딩 속도
2. 데스크톱과 모바일 모두에서 최적화된 탐색 경험
3. 전문적이고 신뢰도 높은 UX/UI
4. 건물과 활성 매물을 빠르게 비교할 수 있는 구조
5. 지역, 빌딩, Insight, Contact가 자연스럽게 연결되는 정보 흐름

시각적 완성도뿐 아니라 정보 밀도, 가독성, 반응형 동작, 탐색 속도까지 모두 프로페셔널한 수준으로 유지한다.

## 3. 검색·AI 최적화 원칙

SEO, AIO, GEO는 선택 기능이 아니라 기본 설계 원칙이다.

- 서울 전역의 `사무실 임대` 검색 의도를 권역·지역·빌딩·매물·Insight로 구조화한다.
- GBD, YBD, CBD, 성수, 송파, 서초, 용산 등 각 권역의 독립적인 검색 진입점을 만든다.
- Building, Listing, Insight 간 내부링크를 강화한다.
- 사용자에게 보이는 요약, 비교 정보, FAQ, Breadcrumb, Schema를 일관되게 제공한다.
- 검색엔진과 생성형 AI가 지역, 건물, 현재 공실, 임대조건, 관련 개념을 쉽게 이해할 수 있게 한다.
- 숨겨진 키워드, 가짜 데이터, 중복 메타, 중복 Schema는 사용하지 않는다.

## 4. 핵심 콘텐츠 방향

### Building 중심 전문 정보

- 빌딩 개요
- 업무권역과 입지
- 외관, 로비, 공용부
- 규모와 주요 사양
- 주차와 접근성
- 주요 입주 기업 및 업종
- 현재 활성 Listing
- 임대조건과 비교 지표
- 관련 권역·지역 매물
- 관련 Insight와 Contact

### Listing 운영

Listing은 개별 공실과 임대조건을 관리하는 내부 데이터이며, 외부 공개의 중심은 Building이다.

### Insight

사무실 임대 체크리스트와 가이드를 쉽고 간결하게 재구성하고, 지역·빌딩·매물·Contact와 연결되는 정보성 콘텐츠로 운영한다.

## 5. 주요 기능 방향

### 기본 기능

- 서울 전역 권역·지역별 For Lease 탐색
- 프라임 오피스 Building 상세
- 활성 Listing 통합 노출
- 지역·면적·임대조건 필터
- 지도 기반 탐색
- Insight 콘텐츠 허브
- Contact 전환
- Leasing Flyer

### 확장 기능

- 대화형 AI 매물 검색
- 자연어 조건 해석
- WordPress DB 기반 매물 추천
- 고객 제안용 Leasing Flyer 자동 구성
- 관리자용 매물·콘텐츠 등록 UI
- 반복 업무 자동화
- AI 기반 검색·상담·추천 기능

AI 기능은 향후 확장 요소지만, 초기 데이터 구조와 URL, 메타데이터, 내부링크는 이를 수용할 수 있도록 설계한다.

## 6. 제품 우선순위

1. 속도와 안정성
2. 데스크톱·모바일 최적화
3. 프로페셔널 UX/UI
4. 프라임 오피스 전문성
5. 서울 전역 권역 확장성
6. SEO/AIO/GEO
7. 관리자 운영 편의
8. AI Agent 및 자동화 확장성

## 7. 에이전트 필수 이해사항

모든 에이전트는 다음을 전제로 작업한다.

- OFFICE LEASING는 강남 중소형 사무실 사이트가 아니다.
- 서울 전역의 프라임 오피스 임대를 전문적으로 다루는 플랫폼이다.
- `사무실 임대`가 핵심 상위 키워드다.
- GBD, YBD, CBD, 성수, 송파, 서초, 용산 등 권역 확장이 기본 목표다.
- 속도, 반응형 최적화, 전문적 UX/UI가 기능과 동일한 수준의 핵심 요구사항이다.
- SEO/AIO/GEO는 모든 템플릿, URL, 콘텐츠, Schema, 내부링크 설계에 기본 적용한다.
- AI Agent와 자동화 기능을 향후 확장할 수 있도록 데이터 구조를 막지 않는다.
